# Overview

The following repository documents the calculations performed for the essay "*Absalom, Absalom!* and the Digital Humanities: Charting Characters, Events, and Language" in the [Norton Critical Edition of *Absalom, Absalom!*](https://wwnorton.com/books/9780393422580). Some of these results have been reworked into a visual essay, which allows for more interactivity and is available here:

- [Absalom, Absalom! and the Digital Humanities: Charting Characters, Events, and Language](https://faulkner.iath.virginia.edu/absalom_characters_events_language/)

As the processing required using materials that are in copyright, some of the data has not been posted on-line. Instead it is stored locally in a folder called `protected_data`. Consequently, the code in the `.rmd` will not run without this data. As a way around this limitation, please see below for all the calculations and samples of the underlying data: 
- [White Paper: Absalom, Absalom! and the Digital Humanities](https://joostburgers.github.io/absalom_four_dimensions/)
